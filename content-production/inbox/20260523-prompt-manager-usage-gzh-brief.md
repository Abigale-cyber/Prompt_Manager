选题: Prompt manager 不是又一个提示词收藏夹，而是把高频 AI 工作变成可调用、可复用、可统计的本地工作台
来源: 用户输入

# 方向锁定

目标读者: 已经在日常工作中频繁使用 ChatGPT、Claude、Codex 等 AI 工具，但提示词仍散落在备忘录、文档、聊天记录里的内容创作者、产品经理和独立开发者。

读者痛点: 读者知道好 Prompt 能提升产出质量，但每次使用时仍要翻找、复制、改字段、粘贴到目标 App，导致高频工作流不稳定，团队或个人也很难沉淀可复用资产。

核心判断: Prompt manager 的价值不在于“存 Prompt”，而在于把 Prompt 从文本资料变成随时可调用的工作流入口；真正应该介绍的是它如何减少查找、改写、复制、粘贴和复用成本。

写作目的: 让读者看完后理解 Prompt manager 适合解决什么问题、核心功能怎么串起来使用、第一次应该如何搭建自己的 Prompt 库，并能判断它是否适合自己的工作流。

切入角度: 从“第一次怎么把 Prompt manager 用起来”切入，用一个完整使用流程串起软件能力：安装启动、建立分类、添加或导入 Prompt、填写模板变量、搜索调用、用 `⌥Space` 在当前 App 上方调出、复制或自动粘贴到目标输入框。

# 结构

推荐框架: 教学类

SCQA:
  情境(S): 现在很多人已经积累了大量 AI 提示词，常见存放位置包括飞书文档、Notion、备忘录、聊天收藏、Excel 表格或浏览器书签。
  冲突(C): Prompt 越积越多之后，真正使用时反而变慢：找不到、记不住适用场景、复制后还要手动替换变量、不同工具之间来回切换，最后又退回临时手写。
  问题(Q): 如果读者第一次打开 Prompt manager，应该按什么顺序使用，才能从“存了一堆 Prompt”变成“随手调出一个可用 Prompt”？
  答案(A): 使用顺序应该是：先运行 Mac 小工具或前端预览；再按工作场景建立分类；添加、编辑或批量导入 Prompt；把高频 Prompt 改成带变量的模板；日常使用时通过搜索或 `⌥Space` 浮窗调出；填写变量后复制或自动粘贴到当前 App；最后根据使用次数清理和迭代 Prompt 库。

# 文章大纲

1. 章节: 为什么你需要一个 Prompt manager
   要回答的问题: 读者为什么不能继续把 Prompt 散放在文档、备忘录和聊天记录里？
   关键内容: 写清楚 Prompt 越多越难用的真实痛点：找不到、场景记不住、变量要手改、复制粘贴耗时，最后又回到临时手写。

2. 章节: Prompt manager 到底是什么
   要回答的问题: 这个软件和普通 Prompt 收藏夹有什么区别？
   关键内容: 定义它是本地 Prompt 管理和调用工具；强调核心价值是把 Prompt 快速调出来并用上，而不是单纯保存文本。

3. 章节: 第一步，安装和打开软件
   要回答的问题: 新用户第一次怎么启动它？
   关键内容: 说明 Mac 小工具运行方式、菜单栏后台入口、`⌥Space` 快捷键、前端原型预览方式，以及测试版 DMG 的打开注意事项。

4. 章节: 第二步，建立第一套分类
   要回答的问题: Prompt 应该怎么分类才方便长期使用？
   关键内容: 建议按工作流分类，例如选题、Brief、写作、审稿、改稿；提醒不要按“收藏来源”分类。

5. 章节: 第三步，添加、编辑和维护 Prompt
   要回答的问题: 单条 Prompt 在软件里怎么管理？
   关键内容: 介绍新增、编辑、删除、启用/停用、搜索、拖拽排序、使用次数记录等基础动作。

6. 章节: 第四步，批量导入已有 Prompt
   要回答的问题: 已经有很多 Prompt 的用户怎么迁移进来？
   关键内容: 说明可以通过 JSON、Excel/表格导入，把已有 Prompt 从文档或表格迁移到工具里，降低初始化成本。

7. 章节: 第五步，把高频 Prompt 改成模板
   要回答的问题: 为什么模板变量比纯文本 Prompt 更适合复用？
   关键内容: 解释 `{{字段名}}` 的用法；调用带变量的 Prompt 时先填写字段，再生成最终 Prompt；可用 AI 改写把关键词补成更适合填入模板的字段内容。

8. 章节: 第六步，在真实工作里调用 Prompt
   要回答的问题: 日常使用时怎样最快把 Prompt 放进当前工作场景？
   关键内容: 介绍管理器内点击调用会复制 Prompt；Mac 工具可用 `⌥Space` 从当前 App 上方调出浮窗，搜索后回车或点击调用。

9. 章节: 第七步，自动粘贴和权限设置
   要回答的问题: 复制和自动粘贴分别需要什么条件？
   关键内容: 说明普通复制不需要额外权限；要自动粘贴到其他 App 的输入框，需要开启 macOS 辅助功能权限。

10. 章节: 一周后如何维护你的 Prompt 库
    要回答的问题: 怎么避免 Prompt manager 也变成另一个杂乱收藏夹？
    关键内容: 建议先放 5 到 10 个最高频 Prompt，连续使用一周，根据使用次数和搜索习惯清理、合并、改写。

11. 章节: 适合谁，不适合谁
    要回答的问题: 读者该如何判断自己要不要用它？
    关键内容: 适合 AI 高频使用者、内容创作者、产品经理、独立开发者；不适合期待成熟云端协作、多人权限管理、企业级 Prompt 平台的读者。
